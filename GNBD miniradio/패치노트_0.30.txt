MINI-RADIO 펌웨어 패치노트 v0.30
====================================
날짜: 2026-10-22
기존 버전: 0.20 → 이번 버전: 0.30

■ 버그 수정 (B)
------------------------------------
B1  [rds.c] RDS 오류비트 해석 순서 역전 수정
    AN332 RESP12 규격에 맞춰 BLEA[7:6]/BLEB[5:4]/BLEC[3:2]/BLED[1:0] 순서로
    err_a/b/c/d 파싱하도록 변경.

B2  [wifi.c] wifi_off() 재시작 버그 수정
    wifi_off() 호출 시 mode가 남아있으면 AP/STA를 다시 재시작하던 문제 제거.
    이제 wifi_off()는 완전히 정지하고 mode를 0으로 초기화.

B3  [si4732.c] 검토 결과 수정 불필요
    gain_db * 256 스케일이 AN332 Q8.8 (0x1000=16.0dB) 사양과 일치함을 확인.
    현행 코드 유지.

B4  [si4732_patch.c] SSB 패치 로드 실패 시 정리 보강
    patch 로드/SSB 모드 설정 실패 시 power_down으로 상태 복구.
    power_down 후 10ms 대기 추가 (칩 안정화).

B5  [main.c] RM_RDS 옵션 적용 시 불필요한 CPU 클럭 변경 제거
    RDS 토글에 cpu_apply()가 잘못 포함되어 있던 문제 수정.

B6  [radio.c] SSB 패치 미리보기/해제 경로 보완
    (radio_ensure_mode의 patch_missing 플래그 로직 정상 동작 확인)

B7  [main.c] 화면 꺼짐 상태에서 HMI_QUICK 복귀 처리
    스크린 오프 타이머 동작 시 HMI_QUICK → HMI_TUNE 복귀.

B8  [eibi.c] HTTP 상태코드 200 검사 추가
    EiBi 다운로드 시 상태코드 != 200이면 실패 처리.

B9  [wifi.c] STA 자동 재연결 (최대 5회)
    WIFI_EVENT_STA_DISCONNECTED 시 esp_wifi_connect() 재시도.

B10 [main.c] OPT 타임아웃 시 HMI_QUICK 복귀 처리

B11 [web.c] BFO/BW 파라미터 클램프
    web API로 들어온 BFO는 ±BFO_MAX_HZ, BW는 0~6으로 제한.

B12 [storage.c] v1→v3 마이그레이션 시 out 구조체 memset 초기화
    이전에 남아있던 데이터로 인한 오염 방지.

B13 [wifi.c] wifi_scan_start() 시 s_wifi_mode 동기화
    mode가 0이면 STA(2)로 설정하고 UI 상태도 갱신.

■ 기능 개선 (F/K/Q/T/C/U/A/S)
------------------------------------
F1-F3 [main.c] UI 레이아웃/폰트 미세 조정 (스킵 - 기존 유지)

K1   [ui.c] Seek 중 헤더에 SEEK% 진행률 표시
     SEEK12% 형태로 현재 스캔 진행률을 헤더에 표시.

K2   [radio.c] ATS 중에도 주파수+헤더 진행률 표시
     ATS 진행 시 주파수 카드와 헤더 SEEK% 동시 갱신.

K3   [radio.c] Seek 스텝을 현재 설정 스텝 사용
     eff_step_hz() 우선 사용, 설정이 -1(밴드 기본)이면 밴드 기본 스텝.

K4   [radio.c] Scan 스텝 밴드별 고정
     FM 100kHz / MW·LW 1kHz / SW·햄 5kHz.
     SPEC_SCAN_MAX 1200 → 5000으로 확대 (더 촘촘한 스캔).

K5   [ui.c] Scan 완료 시 "NO STATIONS" 표시
     스캔 결과가 전부 약신호일 때 그래프 하단에 안내 표시.

K7   [ui.c] ATS/P 복합 배지
     preset_slot + ats_slot 동시 매칭 시 "P3·A2" 형태로 병기.

Q1-Q3 [main.c + ui.c] 퀵바 오버레이 추가
     HMI_TUNE에서 길게 누르면 퀵바 열림.
     4항목: ①VOLUME ②ATS LIST ③FAVORITES ④SCREEN OFF
     회전=커서 이동, 클릭=실행, 롱프레스=닫기.
     20초 타임아웃 자동 닫힘.

T1   [ui.c] FM 스테레오 전용 3번째 바 (스테레오 블렌드)
     SIGNAL 패널에 RSSI/SNR에 이어 STBLEND% 바 추가.
     FM + 스테레오일 때만 표시.

T2   STEREO 설정 유지 (이미 메뉴에 존재, 변경 없음)

C1   [ui.c] 배터리 충전 아이콘 표시
     battery_pill에 충전 중 표시 (번개 모양 심볼).

U1   [main.c] 커서 위치 기억
     page_menu/page_set/open_favorites/open_ats_list에서 커서 초기화 제거.
     전원이 꺼질 때까지 마지막 위치 유지.

A2   [radio.c] ATS 완료 후 목록 자동 열기
     ats_finish()에서 수집된 채널이 있으면 open_ats_list() 호출.

S3   [ui.c] S-meter 라벨 "S1"→"RSSI" 명확화
     SIGNAL 패널과 radio_panel 모두 RSSI 숫자 표시로 변경.

S4   [ui.c] 14세그 seg_bar → 연속 bar로 교체
     RSSI/SNR/STBLEND 바를 연속 그래프로 변경 (부드러운 표시).

S5   [app.h] RSQ_PERIOD 1000ms → 250ms
     신호 폴링 주기 단축으로 반응성 향상.
     main.c의 중복 #define 제거.

■ 알려진 제한사항
------------------------------------
- RDS AF(대안주파수) 파싱은 추가되었으나 자동 튜닝은 미적용 (데이터만 수집)
- CT(시각동기) 파싱 완료, 시계 자동 동기화 로직은 별도 구현 필요
- SSB 패치 로드는 Phase 2 미구현 (패치 데이터 없음)
