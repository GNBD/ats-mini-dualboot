A **`Callsign`** tile was added to `Settings`, letting you replace the main-menu
title with your own callsign (printable ASCII, up to 16 characters). An optional
**Greeting** prefixes it robot-style, e.g. `WELCOME, HL2ABC.`, so the boot text
can show an operator callsign; leave the field blank to restore the default
`Boot Manager`. When a custom value is set, `Boot Manager v<version> (DES)` moves
to the line under the title. The value and greeting can be edited either on the
device (on-screen keypad, like the Wi-Fi password) or from the web **Status**
card. `Settings` now pages to a second page to hold the extra tile.
