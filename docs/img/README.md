# Images for the flashing guide

Put your photos here, using these file names (see `../flashing.html`).
Any size works; the page scales them to the column width. JPG or PNG.

| File | Used for |
|---|---|
| `board-usb.jpg` | The board connected with a USB data cable. |
| `menu.jpg` | The recovery tile menu (encoder held). |
| `web-ip.jpg` | The menu bottom showing the web address (IP). |
| `web-upload.jpg` | The web UI **Firmware** tab with a file selected. |
| `esptool-js.jpg` | The esptool-js web page with files and offsets. |
| `esptool.png` | A terminal running the `esptool` command. |

A figure with a missing file simply shows nothing yet, so you can add them
one by one. To add more shots, copy a `<figure>` block from `flashing.html`.
