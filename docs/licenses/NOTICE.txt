IMPORTANT: Firmware binary distribution
---------------------------------------

Firmware releases from this repository contain code under several licenses.
The application images built from ats-mini-recovery-beta and
ats-mini-recovery-lite link GPL-3.0 covered code (Rotary, section 1), so
those images fall under GPL-3.0 when they are distributed. The bootloader
binaries are Apache-2.0 (section 3.1), and the Arduino-ESP32 core and the

Reaching a device by OTA is distribution as well: sending an application
image over OTA carries the same obligations as a release download, and OTA
is not a separate license.

For GPL-3.0 covered images, provide the corresponding source code (this
repository at the matching commit or tag) and the applicable license
texts.

This repository ships prebuilt second-stage bootloaders built from ESP-IDF and
modified by this repository:

- ats-mini-recovery-beta/bootloader.bin
- ats-mini-recovery-lite/bootloader.bin

and a patch describing the modification:

- ats-mini-recovery-beta/bootloader.patch

When redistributing these files, follow the Apache License 2.0 terms:
