3.1 Prebuilt bootloader (ESP-IDF, Apache-2.0)
---------------------------------------------

This project ships a prebuilt second-stage bootloader built from ESP-IDF and
modified by this project:

- ats-mini-recovery-DBFM/bootloader.bin

and a patch describing the modification:

- ats-mini-recovery-DBFM/bootloader.patch

ESP-IDF v5.5.5 is distributed by Espressif under the Apache License 2.0
(some components under other licenses). The bootloader file above is a
derivative work of ESP-IDF. Its build and modification are documented in
ats-mini-recovery-DBFM/bootloader.md and
ats-mini-recovery-DBFM/bootloader.patch.

When redistributing these files, follow the Apache License 2.0 terms:
retain the applicable copyright, attribution and notice text, include a copy
of the license (LICENSES/Apache-2.0.txt), and state that the files were
modified (the date and the exact change are given by bootloader.md and
bootloader.patch). The bootloader is provided "AS IS", without warranties or
conditions of any kind, as stated in that license.

Other prebuilt platform files that appear in release assets or in flash
instructions (for example boot_app0.bin) come from the Arduino-ESP32
platform package and are not covered by this repository's MIT License.
Their copyright and license terms must be taken from the exact platform
version they come from; this repository does not relicense them.
