ATS Mini Dualboot이란?

ATS Mini 수신기(SI4732 + ESP32-S3)에 부트 매니저를 설치해서, 전원을 켤 때 두 펌웨어(app0, app1) 중 원하는 쪽을 골라 부팅할 수 있게 해 주는 프로젝트입니다. esp32-si4732/ats-mini를 포크해서 만들었습니다.

아직 개발 중인 프로젝트입니다. 앱이 멈추거나, 부팅이 되지 않거나, 데이터가 사라질 수 있으니 주의하세요.

꼭 지켜야 할 규칙

  1. 부트 매니저 바이너리, 파티션 테이블, 커스텀 부트로더는 반드시 같은 세트로 사용하세요.
  2. 다른 flash 크기용 파일을 섞어 쓰면 오프셋이 맞지 않아 부팅되지 않습니다.

What is ATS Mini Dualboot?

A boot manager for the ATS Mini receiver (SI4732 + ESP32-S3). Each time you power on, you choose which of two firmwares (app0 or app1) to boot. It is a fork of esp32-si4732/ats-mini.

Power on
▶
Boot manager
(recovery)
▶
app0 · Firmware A
app1 · Firmware B
This project is still a work in progress. Apps may crash, the device may fail to boot, and data may be lost.

Rules to follow

  1. Always use the boot manager binary, partition table, and custom bootloader together as one set.
  2. Mixing files built for different flash sizes misaligns the offsets, and the device will not boot.

Что такое ATS Mini Dualboot?

Проект добавляет в приёмник ATS Mini (SI4732 + ESP32-S3) менеджер загрузки. При включении питания вы выбираете, какую из двух прошивок — app0 или app1 — запустить. Это форк проекта esp32-si4732/ats-mini.

Проект ещё в разработке. Приложение может зависать, устройство — не загружаться, а данные — пропадать.

Что важно соблюдать

  1. Бинарный файл менеджера загрузки, таблицу разделов и кастомный загрузчик всегда используйте вместе, одним комплектом.
  2. Если смешать файлы для разного объёма flash-памяти, смещения не совпадут, и устройство не загрузится.

Install

Install with the web flasher

No software to install: flash the boot manager and app firmware straight from your browser.

gnbd.github.io/ats-mini-dualboot/install.html

  1. Open the address above in Chrome or Edge.
  2. Click Connect device.
  3. Optionally choose the firmware files for app0 and app1.
  4. Accept the terms.
  5. Click Flash!.
Based on v4.1.2 DES. If you upload a combined image, only the app part is extracted automatically.

Установка через веб-прошивальщик

Ничего ставить на компьютер не нужно: менеджер загрузки и прошивки приложений записываются на устройство прямо из браузера.

Partitions & bootloader

FlashPartition tableRecovery offsetCustom bootloader
16MBats-mini-recovery-theme/partitions.csv0x860000ats-mini-recovery-theme/bootloader.bin

A recovery-first custom bootloader makes sure the boot manager always runs first. It is built with ESP-IDF v5.5.5; the build steps are in ats-mini-recovery-theme/bootloader.md.

If the binary, partition table, or bootloader does not match the others, the device will not boot.

동작 원리

부트 매니저는 esp_ota_set_boot_partition()으로 선택한 앱을 ESP_OTA_IMG_NEW로 지정해, 딱 한 번만 그 앱으로 부팅합니다(one-shot 부팅).

  • 부팅된 앱이 esp_ota_mark_app_valid_cancel_rollback()을 호출하면 정상 부팅으로 인정됩니다.
  • 앱이 정상 확인을 하지 못하거나 실패하면, 다음 부팅 때 다시 부트 매니저로 돌아옵니다.

덕분에 전원을 켤 때마다 부트 매니저가 먼저 뜨고, 앱이 고장 나도 복구 화면으로 돌아올 수 있습니다.

How it works

The boot manager calls esp_ota_set_boot_partition() and marks the chosen app as ESP_OTA_IMG_NEW, so it boots that app only once (a one-shot boot).

  • If the booted app calls esp_ota_mark_app_valid_cancel_rollback(), the boot counts as successful.
  • If the app does not confirm itself or fails, the next boot returns to the boot manager.

So the boot manager appears first at every power-on, and you can always get back to the recovery screen even if an app breaks.

Как это работает

Менеджер загрузки вызывает esp_ota_set_boot_partition() и помечает выбранное приложение как ESP_OTA_IMG_NEW — так оно запускается всего один раз (one-shot).

  • Если запущенное приложение вызовет esp_ota_mark_app_valid_cancel_rollback(), загрузка считается удачной.
  • Если приложение не подтвердит себя или даст сбой, следующая загрузка снова пойдёт через менеджер загрузки.

Благодаря этому при каждом включении первым запускается менеджер загрузки, а если приложение сломается, можно вернуться на экран восстановления.
